# Bricks & Bytes

A polished, responsive one-page website for Bricks & Bytes — a web design and development studio.

## Files
- `index.html` — main website
- `style.css` — all styling and responsive layout
- `script.js` — lightweight scroll-reveal interactions
- `assets/` — place your real project images here

## Run locally
Double-click `index.html` to preview it, or use a local server.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload all files in this folder.
3. Go to Settings → Pages.
4. Choose `main` branch and `/ (root)`.
5. Save.

## Before launch
- Replace the sample project visuals with your real Pure Mint / Robata Jones screenshots.
- Change the email address in `index.html`.
- Add your final Bricks & Bytes logo/wordmark if desired.
- Add your real domain once purchased.
